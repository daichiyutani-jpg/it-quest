## 照合の経過
1. 1回目（照合担当8つ、作成担当とは別）：1,389問・63教材・126図を全件照合 → 問題1,109・教材41・図98が verified。
2. 2回目（1回目とも別の担当8つ）：残りの330件を照合し直し、資料に書いてある事実で問う形に直したものを含めて大半を verified に。
3. 2回照合しても根拠を確かめられなかった16問と、範囲外のおそれがある6問は利用停止（`src/data/verify/raw/x-integration.json`。データ画面に一覧）。
4. 照合済みが20問に足りなかった U01・U09・U51 に、公的資料の事実で問う問題16問を追加（`c7g.js`）し、別の担当が照合。
5. 照合の基準・使ってよい資料・判断の記録は `docs/FACTCHECK.md`、出典の一覧は `docs/SOURCES.md`。

## 残っている注意点
- 照合はAIが公的機関などの資料で行った。人（専門家）は見ていない。
- 定義を書いた公的資料が見つからず、教材・問題から外したシラバスの用語例がある（例：DTP、XAI、ヒューマンインザループ、VRIO の4つの観点、ブルーオーシャン戦略、カニバリゼーション、経験曲線、ベンチマーキング、エンタープライズサーチ）。項目（180）は全部扱っているが、用語例の一部は学べない。
- 根拠が弱いまま verified にした問題（大学サイトの記事・コラム）がある（`docs/FACTCHECK.md`）。
- 個人情報保護法の改正の施行（2027-01-17・2028-07-16）と、2027年度の新試験制度で、教材の見直しが必要になる（`docs/UPDATES.md`）。
