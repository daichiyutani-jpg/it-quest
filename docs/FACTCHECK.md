# 照合の記録（学習アプリ共通ルール §15）

## 方針

- 教材・問題・図は、**作った担当とは別の担当**が、出典を開いて照合する。作成担当は全部 `needs_review` で出し、照合担当だけが `verified` にできる。
- アプリが通常の学習に出すのは `verified` だけ（`src/data/content/index.js`）。`needs_review` と `suspended` は出題しない。
- 照合は **AI（作成とは別のエージェント）** が行った。**専門家（人）による監修は受けていない。**アプリの「データ」画面にもそう表示している。
- 存在しない出典・URL・条文番号を書かない。照合担当が実際に開けた資料だけを `sources` に書き、開けなかったものは使わない。

## `verified` にする条件（すべて満たす）

1. **範囲**：問題の内容が、IPAシラバスVer.6.5（SRC-001）の該当単元の項目・用語例・説明の範囲にある。
2. **正しさ**：正解の根拠となる事実と、誤りの選択肢が誤りである理由を、公的機関・規格団体・IPA などの資料（下記）で確かめた。
   - 計算・アルゴリズムのトレース・SQL などは、式や考え方を資料で確かめたうえで、照合担当が node で計算・実行し直して答えが一致した。
3. **正解が1つ**：他の選択肢に「正しいとも言える」ものがない。問題文・選択肢に読み違えを誘う不備がない。
4. **解説が正解と矛盾しない**：`explain` と `why` が正解・資料と一致する。
5. 法律・制度の名称と中身が照合日時点で現行である。

直せば条件を満たすもの（誤字、紛らわしい選択肢、解説の誤り、正解番号の誤り）は、照合担当が直した内容を `patch` に書き、直した後の内容で `verified` にする。
資料で確かめられないものは `needs_review`（出さない）、内容が誤りで直せないものは `suspended`（利用停止）にし、`note` に理由を書く。

- **大学の講義資料**：国公立大学などの**大学のサイト（.ac.jp など）にある**ものは使ってよい。外部の共有サイト（Speaker Deck など）にだけあるものは、それだけでは `verified` の根拠にしない（U57-q21 を needs_review に戻した）。
- **製品・仕様の提供元の公式文書**（Microsoft・Google・Apple の公式ヘルプ、USB-IF・Bluetooth SIG・NFC Forum などの仕様団体）：**その製品・仕様そのものの機能や数値**を確かめるときだけ使ってよい。一般的な用語の定義の根拠にはしない。
- **範囲外のおそれ**がある問題（シラバスの該当単元の用語例・説明に無い）は出題しない（needs_review のまま。U01-q14、U01-q15、U05-q13、U05-q15、U25-q12、U35-q10）。
- **学会誌の論文**（J-STAGE などの査読のある学会誌）：使ってよい（市販の参考書ではないため）。例：U17 のマシンビジョン。
- **法律に基づく業界の実務指針**（クレジット取引セキュリティ対策協議会の導入ガイド＝割賦販売法の措置の実務上の指針）：規格団体と同じ扱いで使ってよい。例：U16 のカード情報の非保持化。
- **大学の紀要**（私立大学を含む、大学のサイトにあるもの）・**証券取引所の用語集**（日本取引所グループ。MBO など市場の制度の用語）：使ってよい。
- **大学の学術リポジトリの学位論文**（査読なし）：ほかの資料と合わせた補強にだけ使う（それだけを根拠にしない）。2回目では lesson:U51・U51-q02・U51-q12 で補強に使った（いずれもほかの資料あり）。
- **シラバス本文の言い方で書いた教材のページ**：lesson:U51 の画面設計・帳票設計のページは、IPAシラバスの説明どおりの表現で、シラバス以外では確かめていない（教材全体はほかの資料で照合済み）。
- **統合時に戻したもの**：U09-q05（VRIO）。1回目の根拠ページに4つの観点の説明が無いことを2回目の担当が確認したため needs_review に戻した（`raw/x-integration.json`）。
- **根拠が弱いまま verified にしたもの**（2回目の照合。公的機関の定義が見つからず、大学・公的機関のサイトにある記事で確かめた）：U10-q05・U10-q12（プッシュ戦略・プル戦略。開志創造大学のサイトの教員の記事）、U11-q14（GROWモデル。秋田県よろず支援拠点のサイトのコラム）。よりよい資料が見つかれば差し替える。
- 公式サイトが自動取得を拒む場合（経済産業省・特許庁・中小企業庁・JISC など、HTTP 403）は回避しない。同じ内容を載せた別の公的機関の資料で確かめる。
