# 必要学習量の見積り（学習アプリ共通ルール §12）

作成：2026-11-06。式は `src/core/planner.js` の `unitMinutes` と同じ。本アプリ独自の見積りで、IPAの公表値ではない。

## 1単元あたり（未学習の単元）

| 内容 | 分 |
|---|---|
| 説明（2〜4ページ）・図解・重要用語・具体例・補足 | 約16 |
| 練習問題3問（その場で解説） | 約3 |
| 小テスト10問（1問約1分12秒の本番ペース）＋見直し | 約12 |
| 合計 | **31** |

学習途中（説明を読んだ）は14分、要復習は14分（復習＋再テスト）、基礎理解済み以上は0分。

## 全範囲（63単元）

| 知識の目安 | 係数 | 単元の学習 | ＋復習2割 | 30日×120分（60時間）と比べて |
|---|---|---|---|---|
| ほぼ初めて | 1.3 | 31×63×1.3 ≒ 2,539分（42.3時間） | ≒ 3,174分（**52.9時間**） | 収まる（残り約7時間） |
| 少し分かる | 1.1 | ≒ 2,148分（35.8時間） | ≒ 2,685分（**44.8時間**） | 収まる |
| 仕事で使っている | 0.95 | ≒ 1,855分（30.9時間） | ≒ 2,319分（38.7時間） | 収まる |
| かなり詳しい | 0.85 | ≒ 1,660分（27.7時間） | ≒ 2,075分（34.6時間） | 収まる |

- 「復習2割」は、使える時間のうち2割を復習（間違えた問題・復習予定の問題・再テスト）に回す前提（`REVIEW_RESERVE = 0.2`）。
- 再テストが何度も必要な単元が多いと、この見積りより増える。実際の学習時間・小テストの結果で、計画は毎回見直す。
- 60時間に収まらないと見積もった場合（受験経験・自己評価・実績から）、アプリは「足りない見込み」と根拠の数字を表示し、達成できるとは言わない（`buildPlan` の `need60`）。

## 30日計画の前提

- 1日120分・30日・合計60時間（共通ルール §12）。
- 模擬試験と最終的な実力確認は 31日目以降（30日間の計画には入れない）。
- 本番形式の練習には「公式の過去問」（利用者が取り込む4年分・各100問120分）も使える。
