# IT QUEST（アイティークエスト）0.2.0

ITパスポート試験の合格をめざす、スマートフォン向けの学習ゲームです（PWA・依存パッケージなし・サーバー不要）。
学習の**実績に合わせて計画が変わる**ことを中心に作っています。

## できること
- **初回設定**：受験日（未定でも可）、平日・土日祝の学習時間、今日の学習時間、自己評価、学習経験、1回の時間、週の日数 → 現在地と最初の内容を表示
- **学習計画の自動調整**（`src/core/planner.js`）
  - 直近14日の実際の学習時間で見込みを補正（実績3日分から反映）
  - 順調／要調整／要集中の判定と、具体的な対策の文章
  - 数日空いたら再計画、受験日を変えると直前対策の開始日も変わる
  - 時間が足りないときは**後回しの単元を一覧で表示**（省略しない）
  - 理解が不十分な単元は、新しい単元より先に補強を入れる
  - 10〜120分の学習時間に合わせて、その回の内容を組み直す
  - 計画の変更履歴を保存
- **試験範囲**：IPA公式シラバス Ver.6.5（2026-01-08掲載、2026-11-05確認）の 3分野・63単元（小分類）・180項目
- **学習画面**：説明 → 重要用語 → 具体例 → 初学者向け補足 → 確認問題 → 正解と解説（選択肢ごとの理由）→ 間違えた理由 → 復習登録
- **問題演習**：単元別・分野別・ランダム・間違えた問題・復習リスト・苦手分野・復習（間隔反復）・制限時間付き・総合模擬試験（100/50/20問、35:20:45の比率）・重要用語カード
- **理解度**：未学習／学習中／基礎理解済み／要復習／習得確認済み（習得確認には、日を空けた再正解が必要）。正答率は初見と復習を分けて集計
- **公式の過去問（IPA公開問題）**（`#/past`、`src/ui/past.js`・`src/core/pastimport.js`・`src/data/past.js`）
  - 令和5〜8年度の4年分・400問。**問題文はアプリに入っていません**。利用者がIPAのサイトから問題冊子PDFをダウンロードし、端末の中で読み込みます（pdf.js同梱・送信なし）
  - 画素から「問N」の行を見つけ、年度ごとのページ情報と照合して1問ずつ画像に切り出し、IndexedDB「it-quest-past」に保存（バックアップには含めない）。並びが合わないPDF（別の年度など）は取り込まない
  - 正答はIPA公開の解答例を収録。単元の分類・解説・覚えるポイントは本アプリ独自（AI作成、人による全問確認は未了）。各問に出典を表示
  - 本番形式（100問120分・中断再開可）、分野別、学習済み単元だけ、間違えた問題、未回答。回答は単元の正答率に反映され、計画に使われる
- **重要度（★）は出題実績から**：令和5〜8年度の400問を単元に分類した出題数（`pastFreq`）で、4年で9問以上→★3、4〜8問→★2、3問以下→★1。計画の優先順位にも出題数を加味
- **直前対策モード**：受験日の7日前（設定で変更可）から自動。未学習の重要単元は切り捨てない
- **ゲーム要素**：経験値・レベル（努力の記録として表示）・連続学習・称号15種・3つの大陸と町（中分類）・合格への試験塔・オリジナルキャラクター「ピコ」
- **音**：効果音とBGMをWebAudioで合成（音声ファイルなし）。ミュート・音量調整あり
- **保存**：IndexedDB（使えない場合は localStorage）。JSONで書き出し・読み込み。中断した演習・学習は「続きから再開」

## 起動方法（PCで試す）
Node.js 18以上が必要です（npm install は不要）。

```bash
cd it-quest
node tools/serve.mjs
```
http://localhost:8795/ を開きます。GitHub Pages と同じサブパスで試すときは `node tools/serve.mjs 8796 /it-quest/` → http://localhost:8796/it-quest/

PowerShellで `npm` が動かない環境では、上のとおり `node` を直接使ってください。

## テスト
```bash
node --test tests/*.test.mjs
node tools/validate.mjs
```
- `tests/core.test.mjs`：理解度判定、初見／復習の区別、実績による計画の変化、空白日の再計画、受験日変更と直前対策、後回しの明示、学習時間別の内容、補強優先、模試の分野比率、復習の出題、バックアップ往復、連続学習（15件）
- `tests/past.test.mjs`：公開問題の年度データ（各年100問・正答・単元・分野区分、令和8年度の正答を解答例と照合）、切り出し位置の計算、年度の候補、分野別採点（4件）
- `tools/validate.mjs`：教材・問題の形式、ID、正解番号、解説の数、シラバス項目のカバー率

## 公開方法（GitHub Pages）
1. `node tools/build-sw.mjs` を実行（オフライン用のファイル一覧と版を更新。**ファイルを変えたら毎回**）
2. `it-quest` フォルダの中身をそのまま GitHub リポジトリに置く（ビルド不要。`tools/` `tests/` `docs/` は置いても動作に影響しません）
3. GitHub の Settings → Pages → Branch を `main` / `/(root)` にして保存
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く（すべて相対パス・ハッシュ方式の画面切り替えなので、サブパスでも動きます）

スマホでは、iPhone は Safari の共有 →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」。一度開いたあとはオフラインで使えます。
アプリを更新すると、次に開いたときに新しい版に切り替わります。学習データ（IndexedDB）は消えません。
