# IT QUEST（アイティークエスト）0.3.0

ITパスポート試験の学習用の、スマートフォン向けアプリです（PWA・依存パッケージなし・サーバー不要・オフライン可）。
学習アプリ共通ルール（`~/.claude/learning-apps/RULES.md` v1）に合わせています。プロジェクト固有の決定は `CLAUDE.md`。

> **状態**：学習開始前の品質確認（`docs/READINESS.md`）が終わるまで、アプリは「準備中」と表示し、30日計画の開始日を設定できません。
> 合格を保証するものではありません。

## できること
- **試験範囲**：IPA公式シラバス Ver.6.5 の 3分野・63単元・180項目（`src/data/syllabus.js`、対応表は `docs/COVERAGE.md`）
- **出題するのは照合済み（verified）の教材・問題・図だけ**：作成と照合は別の担当（AI）。照合の基準と記録は `docs/FACTCHECK.md`、出典は `docs/SOURCES.md`。未照合・利用停止のものは出さず、「データ」画面に数を表示
- **学習画面**：説明 → 重要用語 → 具体例 → 図解（コマ送りのアニメーション）→ 初学者向け補足 → 練習問題3問
- **小テスト**：1単元10問。答えるたびに ⭕/❌ だけ表示し、10問の後に間違えた問題から解説。9問以上で合格。不合格なら間違えた所を復習 → 別の問題で再テスト
- **自信の記録**：答えるときに「自信あり／たぶん／勘」を選ぶ。自信のない正解も復習に入れる
- **理解度**：未学習／学習中／要復習／基礎理解済み（説明＋小テスト合格）／習得確認済み（2日以上空けて別の問題でも正解）。判定の詳細は `docs/DESIGN.md`
- **復習（間隔反復）**：間隔 0・1・3・7・16・35日。自信・繰り返しの間違いで間隔を短くする
- **間違えたとき**：選択肢ごとの理由、別の説明（図解・具体例・やさしい説明・用語の意味）、間違えた理由の記録と傾向の集計
- **30日計画**：1日120分が初期値（変更可）。模擬試験は31日目以降。実際の学習時間で見込みを補正し、遅れたら後回しの単元を一覧で示す。必要時間の見積りは `docs/ESTIMATE.md`
- **初回の基礎の確認**（10問・とばせる）で開始点をおすすめ
- **合格の目安**：分野ごとに範囲・初見・本番形式・定着・要復習から判定（％の合格確率は出しません）
- **公式の過去問（IPA公開問題）**（`#/past`）：令和5〜8年度・400問。問題文はアプリに入っておらず、利用者がIPAのサイトからPDFを入手して端末の中で読み込みます（送信なし）
- **ゲーム要素**：経験値・レベル・連続学習・称号・キャラクター「ピコ」
- **保存**：この端末の IndexedDB だけ（使えない場合は localStorage）。送信・クラウド同期・バックアップはありません

0.3.0 で削除したもの：効果音・BGM（共通ルールで端末の音を使わない）、JSONのバックアップ（書き出し・読み込み）。

## 起動方法（PCで試す）
Node.js 18以上（npm install は不要）。

```bash
node tools/serve.mjs
```

http://localhost:8795/ を開きます。サブパスで試すときは `node tools/serve.mjs 8796 /it-quest/`。

## 検証
```bash
node tools/validate.mjs
```

```bash
node --test tests/*.test.mjs
```

```bash
node tools/merge-verify.mjs
```

```bash
node tools/build-coverage.mjs
```

- `validate.mjs`：教材・問題・図の形式、ID、正解番号、status・sourceIds・tags、単元ごとの問題数（20問以上）
- `tests/`：理解度・小テスト・自信・復習間隔・計画・合格の目安・照合前は出さないこと・移行（v1→v2）・過去問データ など（30件）
- `merge-verify.mjs`：照合担当の結果（`src/data/verify/raw/*.json`）を `verify/all.js` などに反映
- `build-coverage.mjs`：シラバス項目と問題の対応表

## 公開（GitHub Pages）
公開・更新は**毎回、本人の承認を得てから**行います。
1. `node tools/build-sw.mjs`（オフライン用のファイル一覧と版を更新。ファイルを変えたら毎回）
2. フォルダの中身を GitHub リポジトリに置き、Pages を `main` / `/(root)` に設定

iPhone は Safari の共有 →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」。

## ファイル構成
| 場所 | 内容 |
|---|---|
| `src/data/syllabus.js` | シラバスの単元・項目 |
| `src/data/content/c1〜c7f.js` | 教材・問題・図（書き方は `docs/CONTENT_SCHEMA.md`。作成時は全部 `needs_review`） |
| `src/data/verify/` | 照合結果（`raw/` が担当ごとの結果、`all.js` が反映用） |
| `src/data/sources.js`・`sources-extra.js` | 出典の一覧 |
| `src/data/readiness-manual.js` | 人が実施した確認の記録（実施していないものは未実施のまま） |
| `src/data/past.js` | 公開問題の年度情報（問題文なし） |
| `src/core/` | 理解度・小テスト・復習（mastery）、出題（picker）、計画（planner）、合格の目安（judge）、品質確認（readiness）、保存（store） |
| `src/ui/` | 各画面。図解は `figure.js` |
| `docs/` | 公式情報・出典・照合・設計・見積り・権利・更新履歴 |

## 未完成・注意点
- 照合は**AIのエージェント**が公的機関などの資料で行いました。**専門家（人）の監修は受けていません。**
- 実機（iPhone・Android）での確認はまだです。PCのブラウザで幅375pxの表示とオフライン動作を確認しました。
- iPhone の Safari は、しばらく使わないと保存データが消えることがあります（ホーム画面に追加すると残りやすい）。
- 2027年度に新しい試験制度が予定されています（シラバス案 Ver.0.1、2026-08-31掲載）。案の段階のため教材は Ver.6.5 のままです（`docs/OFFICIAL.md`）。
- 重要度（★）・必要時間・合格の目安の数値は本アプリの判断で、IPAの公表値ではありません。
